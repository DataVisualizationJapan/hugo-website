# コンテンツ運用ガイド

Data Visualization Japan のサイトは「YouTube の講演動画を、検索できる書き起こし記事に変換する」ことを軸にしています。1人でも続けられるよう、記事作成を半自動のパイプラインにしています。

## 1. 記事（書き起こし）を作る

### 手順

1. **新規作成**（アーキタイプから型が展開されます）
   ```bash
   hugo new posts/<slug>/index.md
   ```
   `archetypes/posts.md` の front matter がそのまま入ります。

2. **書き起こしの下書きを用意する**
   - YouTube の自動字幕（文字起こし）をたたき台にします。ゼロから書き起こさないのがコツ。
   - 自動字幕を LLM に渡し、「整文・見出し付け・3行要約・タグ候補」を一括で下書きさせると速いです。

3. **front matter を埋める**

   | 項目 | 内容 |
   |---|---|
   | `title` | `LT：登壇者名／タイトル` の形 |
   | `slug` | URL に使う識別子（`/<slug>/` になる） |
   | `date` | 開催日（または公開日） |
   | `author` / `speakers` | 登壇者 |
   | `event` | 紐づくイベントの ID（`content/events/<id>` のフォルダ名） |
   | `videoId` | YouTube 動画 ID（例: `CTQHwFCKpw0`） |
   | `categories` | `["meetup", "<開催年>"]` |
   | `tags` | トピック（配色 / 地図 / D3.js など） |
   | `image` | サムネイル（`images/cover.png`） |
   | `summary` | 検索結果・SNS に出る要約（1〜2文） |

4. **本文を作る**
   - リード文 → `<!--more-->` → 動画埋め込み → 書き起こし本文、の順。
   - 動画は youtube ショートコードで埋め込みます（既存記事 `content/posts/lt-all-about-dataviz/index.md` を参照）。
   - スライド画像は `images/` に置き、`![](images/p02.png)` の形で本文に挿入します。

5. **公開する**
   - 確認できたら `draft = true` を削除（または `false`）。
   - `git push` すると Netlify が自動でビルド・公開します。

### 優先順位

再生数の多い動画・普遍的なテーマ（配色、チャートの選び方など「何年後でも読まれる」もの）から記事化すると、検索流入の効果が高いです。

## 2. イベントページを作る

1. **新規作成**
   ```bash
   hugo new events/<id>/index.md
   ```
   `archetypes/events.md` の型が入ります（`<id>` は `2025-meetup` など）。

2. **front matter を埋める**
   - `eventDate` … 実際の開催日時。この値で「開催予定 / 過去」を自動で振り分けます。
   - **開催予定のイベントでも `date`（公開日）は今日以前**にしてください。未来日にするとビルドされません。
   - `peatix` / `connpass` … 申込リンク。`sessions` に各講演（タイトル・登壇者・`videoId`・`post`）を並べます。
   - `post` には対応する書き起こし記事の `slug` を入れると、イベントページから記事へリンクされます。

3. 記事側の front matter にも `event = "<id>"` を入れておくと、イベントと記事が相互にひも付きます。

## 3. 次回イベントの CTA について

- 全ページ下部のバー、記事末尾のブロックは **events セクションから「最も近い未来のイベント」を自動抽出**して表示します。
- **未来のイベントがある間だけ表示**され、無ければ自動で消えます。
- つまり、次回開催が決まったら **イベントページを 1 本作るだけ**で、サイト全体の告知が自動で切り替わります（`data` ファイル等の二重管理は不要）。

## 4. コミュニティへの導線

左サイドバーの各アイコン（YouTube / Facebook / connpass）は `hugo.toml` の `[[menu.social]]` で管理しています。追加・変更はそこを編集してください。アイコンが無い場合は `assets/icons/<name>.svg` に SVG を置けば使えます。
